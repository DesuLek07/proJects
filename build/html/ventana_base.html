Ventana Base Module¶

Este módulo contiene la clase VentanaBase, que se utiliza para crear la ventana principal de la aplicación.

class ventana_base.ventana_principal(titulo='SRPP', tamaño=(1200, 650, 70, 25), tema='dark', minimo=(1200, 650), maximo=(1200, 650), ruta_fondo=None)[fuente]¶

Bases: object

Clase base para la ventana principal de la aplicación SRPP. Permite definir título, tamaño, tema visual y comportamientos básicos.

cerrar_ventana()[fuente]¶

Cierra la ventana y finaliza la aplicación.

construir_interfaz()[fuente]¶

Método para construir la interfaz gráfica. Se espera que las clases hijas sobrescriban este método.

iniciar_ventana()[fuente]¶

Inicia el bucle principal de la ventana.

mostrar_ventana_principal()[fuente]¶

Muestra la ventana si estaba oculta y la trae al frente.

ocultar_ventana()[fuente]¶

Oculta temporalmente la ventana principal.
