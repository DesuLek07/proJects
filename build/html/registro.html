Registro Usuario Module¶

Este módulo contiene la clase Registro, que se utiliza para crear la ventana principal de la aplicación.

class registro.ventana_registro(menu_ref)[fuente]¶

Bases: ventana_principal

Ventana de registro de usuario para el sistema SRPP.

Hereda de ventana_principal y permite el ingreso de datos personales y credenciales para registrar un nuevo usuario en el sistema. Contiene validaciones básicas y envía los datos a la base de datos.

construir_interfaz()[fuente]¶

Construye la interfaz gráfica de la ventana de registro.

lanzar()[fuente]¶

Lanza la ventana de registro y comienza el bucle principal.

volver_ventana_principal()[fuente]¶

Oculta la ventana actual y muestra nuevamente el menú principal.
