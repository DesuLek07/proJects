Dashboard Usuario Module¶

Este módulo contiene la clase DashboardUsuario, que se utiliza para crear la ventana principal de la aplicación.

class dashboard_usuario.ventana_dashboard(id_usuario, menu_ref, imagen_fondo_ctk=None)[fuente]¶

Bases: ventana_principal

Clase que representa el panel principal para el usuario. Hereda de ventana_principal y carga la interfaz de usuario con sus datos, opciones para enviar PQR, ver historial de tickets y respuestas recibidas.

abrir_historial()[fuente]¶

Muestra una ventana con el historial de tickets enviados por el usuario. Incluye opción para descargar archivos adjuntos si existen.

abrir_pqr()[fuente]¶

Abre una nueva ventana para que el usuario envíe una PQR (Petición, Queja o Reclamo). Permite adjuntar un archivo opcional (hasta 2MB).

construir_interfaz()[fuente]¶

Construye la interfaz gráfica del dashboard con los datos del usuario, botones de navegación y contenedores visuales.

lanzar()[fuente]¶

Inicia la ventana de dashboard y entra en el bucle principal.

mostrar_info_usuario()[fuente]¶

Muestra una ventana emergente con el ID del usuario actual.

ver_respuestas()[fuente]¶

Abre una ventana con las respuestas asociadas a los tickets enviados por el usuario.

volver_ventana_principal()[fuente]¶

Muestra nuevamente el menú principal desde el dashboard.
